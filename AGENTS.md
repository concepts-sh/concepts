# concepts

This repository holds the Concepts standard: the specification (`SPEC.md`), the skill (`skills/concepts/`), the command (`cli/`), and the site (`site/`). The repository's own concept base in `.concepts/` describes the standard in its own format.

## Concepts

Read `.concepts/index.md` before you work on domain logic. Open a concept file when a task touches the concept. Follow the concepts skill to add or change concepts.

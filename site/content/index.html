An open format for agent knowledge

Give your agents the meaning of things.

A .concepts/ folder of plain markdown that defines what each term, entity and idea in your project is, and how they connect. Skills tell an agent how to do a task. Concepts tell it what things are.

npx concepts initor create the folder by hand. No tool is required.

Intelligence means having a sufficient number of clear, correct and essential concepts in your mind, and having established a sufficient number of clear, correct and essential connections among them.

One concept, one file

Two required fields, the same two as a skill: a title and a one-sentence definition. The body is free. Connections are sentences whose first word is the type of relationship, so the file reads like prose and parses like data. The map sits in context on every turn; the file is one hop away.

Why concepts

Agents fail at meaning before they fail at code

A model knows what a database index is. It cannot know what your team means by "workspace", which of three revenue numbers is the real one, or that a finalized invoice must never change. That knowledge is local, and no training run will ever contain it.

Correct once

When the agent misunderstands a term, the fix goes into the concept file, not into one more line of the prompt. Every teammate's agent has it from then on. Nobody writes a knowledge base up front; it grows from corrections.

Connections are half the meaning

"Invoice" alone says little. "Part of a workspace, never of a user" and "not a receipt" are what prevent the bug. Each connection is a typed claim, and the map carries them, so the agent sees the shape of the domain, not just a list of words.

How it works

  1. The map is always in context. AGENTS.md points to .concepts/index.md, one line per concept with its definition and connections. About a hundred concepts fit in 4,000 tokens.
  2. Files load on demand. When a task touches a concept, the agent opens its file. The connections on the map line say which neighbours to open too.
  3. The agent maintains it. A skill teaches the agent when to add, fix, update and retire concepts, in the same change as the code. People review the diff like any other.

Eight relationship types

The type is the first word of the sentence; the rest of the sentence is the claim. Conditions and differences go after the colon.

FamilyOpenerQuestion it answers
KindKind of X · Kinds: X, YWhat is it, more generally?
PartPart of X · Parts: X, YWhat contains it?

When a relationship needs its own definition, it is a concept. Settlement is the relationship between a payment and an invoice, so Settlement gets a file with two connections.

Works with any agent

A concept base is markdown files and one line in AGENTS.md, so it works today in every agent that reads that file: Claude Code, Codex, Cursor, Copilot, Gemini CLI and the rest. No vendor has to add support. The optional CLI (init, check, wiki) is one file with no dependencies, and the files are also valid for the Open Knowledge Format, Obsidian and any markdown viewer.

Questions

Is this memory?
No. Memory is what an agent privately remembers about past sessions, and every vendor ships its own. Concepts are shared, reviewed meaning: in git, visible to the whole team, readable by any agent.
Why not a database or a graph store?
Files in git are readable by every agent, reviewable in a pull request, and need no runtime. The graph is derived from the files whenever it is needed, by the CLI, the wiki, or a grep for backlinks.
Can I share a base?
Publish it: push the repo. Others link to your concepts by URL, pinned to a version, and write local concepts in their own words when they need yours in mind. Nothing is copied, so titles never collide.
Do I need the CLI?
No. The format needs no tool. The CLI installs the skill, checks a base in CI, and builds a disposable wiki to read a base in a browser.
How big should a base be?
Start with ten to twenty concepts: the terms used everywhere, the ones with two meanings, the ones nobody has written down. Grow it from corrections. Essential beats complete.

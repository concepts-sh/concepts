A base is any folder with a [map](map.md). A project's base is `.concepts/` at the root of the repository. A base holds only its own [concepts](concept.md); another base is linked, never copied. Titles are unique within a base.

Example: `.concepts/`, this repository's base.
Source: `SPEC.md`, section 1.

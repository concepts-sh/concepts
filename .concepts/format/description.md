---
title: Description
description: The one sentence in a concept's front-matter that defines it.
---
A reader must be able to use the [concept](concept.md) correctly from the description alone. It is a definition, not a summary of the body: what the thing is, and what sets it apart. It is the only field other than `title`, and it is repeated on the concept's line in the [map](map.md).

Example: the `description:` line at the top of this file.
Source: `SPEC.md`, section 2.

## Connections
- Part of a [concept](concept.md), in its front-matter.
- Required by the [map](map.md), which repeats it on every line.
- Uses the [style](style.md) rules strictly.
